How it works

  1. Paste a URL or add the Action. Point us at a public https MCP endpoint, or start the server in the GitHub Actions runner and scan http://127.0.0.1.
  2. We probe the surface agents see. initialize, tools/list, an unknown method, a foreign Origin, a CORS preflight, and OAuth discovery. No side-effect tool calls.
  3. You get a score and a token bill. A 0–100 readiness score, the approximate tokens tools/list costs every turn, and the top issues.
  4. Ship with a badge, keep it from drifting. Drop the README badge and gate every PR with the Action.

FAQ

How do I test an MCP server in production?

Paste its public https URL into the scanner above. It connects the way Claude, ChatGPT and Cursor do, sends initialize and tools/list, an unknown method, a foreign Origin, a CORS preflight and the OAuth discovery requests, and returns a 0–100 score with the top issues. To test before production, run the free GitHub Action against localhost in CI.

How many tokens does an MCP server cost per turn?

Its whole tools/list is sent to the model on every turn. On 20 November 2026 popular open servers ranged from about 80 tokens (Astro Docs) to about 4,967 tokens (Hugging Face). The scan reports the estimate for your server. Token counts are estimates.

Do MCP servers have to validate Origin?

Yes. The MCP Streamable HTTP transport says servers MUST validate the Origin header to prevent DNS-rebinding attacks. In our 13 November 2026 registry scan, 44% of public servers accepted a foreign Origin.

Is this a security audit?

No. It is an automated surface scan of what any client sees before login. It is a triage signal, not a substitute for a review of auth, data flows and approval gates.

Is it free?

Yes. The web scan (10 per hour), the public page per server, the README badge, the open-source CLI and the GitHub Action (50 runs per day per repo) are free with no sign-up. Pro is coming soon and has no price yet.
