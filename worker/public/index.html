How it works

  1. Paste a URL or add the Action. Point us at a public https MCP endpoint, or start the server in the GitHub Actions runner and scan http://127.0.0.1.
  2. We probe the surface agents see. initialize, tools/list, an unknown method, a foreign Origin, a CORS preflight, and OAuth discovery. No side-effect tool calls.
  3. You get a score and a token bill. A 0–100 readiness score, the approximate tokens tools/list costs every turn, and the top issues. Pro adds the full report, the slim tools.json, and the CI growth gate.
  4. Ship with a badge, keep it from drifting. Drop the README badge. On Pro and Team, re-scan on a schedule and get a webhook if the score or token budget moves.

FAQ

Is this a security audit?

No. It is an automated surface scan of what any client sees before login. It is a triage signal, not a substitute for a review of auth, data flows, and approval gates.

How is this different from CheckMCP, Snyk Agent Scan, or MCPWatch?

CheckMCP is the closest hosted comp; we compete on a larger live official-registry corpus, a localhost CI Action, and a Pro tool-list rewrite. Snyk Agent Scan checks configs and skills on developer machines. MCPWatch grades repository source against OWASP-style checks. Use them together when they overlap.

Why pay if the public scan is free?

Free shows the score, the token cost, and the top 3 issues. Pro unlocks every finding with a fix, the slimmer tools.json, private or OAuth-gated scans, a hosted report, and a CI gate on growth. Payment never changes the score.

Can I scan localhost or a server behind login?

The GitHub Action runs in your runner and can scan localhost. Pro accepts a test-tenant token for tools behind login. The public web form only accepts public https URLs.

How do you measure tokens, and what does the 70% Notion figure mean?

Token counts are estimates. ToolSlim's zero-dependency estimator came out 1–9% above o200k_base on a 14-server set, 13 Nov 2026. The 70.2% cut (17,477 to 5,213 tokens) is the lossless safe rewrite of Notion's official server on that date, at the stated price assumption of 1,000 calls/day and $3 per 1M input tokens with no cache. Other servers in the same demo saved much less at the lossless level (for example Chrome DevTools 9%, Playwright 12%). Treat the dollar figures as a budget scenario, not a bill.
