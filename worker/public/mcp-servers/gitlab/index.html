FAQ

How many tokens does GitLab MCP server add?

Token cost is not available without login. The GitLab tool list sits behind authentication, so this unauthenticated scan could not count tools or tokens.

Does GitLab support OAuth discovery?

Yes. An unauthenticated scan of the GitLab MCP server reached a login wall and found no open pre-login OAuth discovery issues.

How do I test my own MCP server like GitLab?

Paste its URL into the free scan at https://mcp-readiness.omer20sh.workers.dev/ for a score, token cost and top issues, then add the free GitHub Action (Om3rr/mcp-readiness-check@v1) to fail PRs under a score or over a token budget. Local servers work too: start the server in CI and scan http://127.0.0.1.
