FAQ

How many tokens does Exa Search MCP server add?

About 605 tokens per agent turn for 2 tools, measured by a live unauthenticated scan on 20 November 2026. The tool list is sent to the model on every turn.

Does Exa Search support OAuth discovery?

It does not need OAuth to list tools: tools/list answers without login, which is common for public read-only servers.

How do I test my own MCP server like Exa Search?

Paste its URL into the free scan at https://mcp.pacerai.fit/ for a score, token cost and top issues, then add the free GitHub Action (Om3rr/mcp-readiness-check@v1) to fail PRs under a score or over a token budget. Local servers work too: start the server in CI and scan http://127.0.0.1.
