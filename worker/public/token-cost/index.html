MCP server token cost ranking

Every MCP server you connect sends its tool list to the model on every agent turn. This table ranks 450 public MCP servers by the measured size of that tool list, lightest first. Token counts are estimates (about ±10%).

On 27 November 2026 we scanned 46,630 unique remote endpoints from the 75,977 servers listed in the official MCP Registry (plus the servers on the earlier ranking), without login: 28,387 returned a tool list with at least one tool, 196 returned an empty tool list, 13,428 required login and 4,619 did not answer or failed. This page covers 500 of them (at most 2 new servers per registry publisher); the raw data has all of them. Of the 25 servers measured both on 20 November and 27 November 2026, 18 changed token cost.

Lightest: Google Classroom (~1 tokens). Heaviest: iDos Games (~456,599 tokens). All 450 together: ~11,807,062 tokens per turn.
